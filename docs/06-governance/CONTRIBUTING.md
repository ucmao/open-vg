# Contributing to VidGen

Thank you for your interest in contributing to VidGen! We welcome pull requests, bug reports, feature suggestions, and documentation improvements from global developers.

---

## 🚀 How to Contribute

### 1. Reporting Issues
- Search existing GitHub Issues before filing a new bug report.
- Include OS version, browser version, error tracebacks, and reproduction steps.

### 2. Submitting Pull Requests (PRs)
1. Fork the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Follow coding standards:
   - **Backend**: Python 3.11, PEP 8 styling, type annotations.
   - **Frontend**: Vue 3 `<script setup lang="ts">`, ESLint, Tailwind CSS.
3. Add unit tests or verify existing tests pass.
4. Commit changes with clear commit messages (`feat: add wan2.1 video provider adapter`).
5. Open a Pull Request targeting the `main` branch.

---

## 📜 Commit Message Conventions

We follow Conventional Commits:
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation changes
- `refactor`: Code refactoring without functionality changes
- `test`: Adding or updating tests
